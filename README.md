# Project-Survivor
A multiplayer "Survivor-like" game using Mirror

## Security and Access Control

For information on how to protect your project files and restrict access, please see [SECURITY.md](SECURITY.md).

**Quick Summary:**
- To restrict access on GitHub: Make your repository private in Settings → Danger Zone → Change visibility
- To protect local files: Use appropriate file system permissions (chmod 700 on Linux/macOS)
- For sensitive data: Never commit API keys, credentials, or secrets to version control
